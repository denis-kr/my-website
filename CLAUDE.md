# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Personal portfolio/resume website built with React Router v8 in **Framework Mode** (SSR enabled), Vite, React 19, and Tailwind CSS v4.

## Commands

The package manager is pnpm (`pnpm-lock.yaml`).

- `pnpm dev`: dev server with HMR (http://localhost:5173)
- `pnpm build`: production build to `build/client` and `build/server`
- `pnpm start`: serve the production build with `react-router-serve`
- `pnpm typecheck`: runs `react-router typegen`, then `tsc`. This is the only static check; there is no linter or test suite.

## Architecture

- **Routing is configured explicitly** in `app/routes.ts`. Files in `app/routes/` are not file-system routed, so a new page needs an entry there. There are only three routes:
  - `/` (`routes/home.tsx`): a single long page. The hero is followed by the About ("Me"), Projects, Experience, Hobbies and Contact sections, which are anchors (`#about`, `#projects`, …), not separate routes.
  - `/ai` (`routes/ai.tsx`): the chat. The hero's ask box submits `?q=` here, and the loader redirects to `/` if `q` is missing. Both ask boxes share `view-transition-name: ask-box` so the box glides between pages.
  - `*` (`routes/not-found.tsx`): catch-all that returns a real 404 status from its loader. Keep it last.
- **`app/root.tsx`** holds the HTML shell (`Layout`), the font links, and the app-wide `ErrorBoundary`. That boundary handles thrown errors (a thrown 404 gets the not-found page); ordinary unknown URLs are handled by the catch-all route. Both error pages are built from `components/error/`: the `ErrorPage` layout (which also exports `primaryButton`/`secondaryButton`/`codeChip` classes), the `ArchWindow` frame with its `LakeView`/`StormView` scenes, `NotFoundPage`, and `SectionJumpLinks`. The stack trace only shows in dev.
- **Components** live in `app/components/<area>/`, one folder per section or feature (`about`, `projects`, `experience`, `hobbies`, `contact`, `hero`, `nav`, `ai`, `section`, `error`). Shared pieces:
  - `owner.ts`: the `OWNER` name/title. Use it instead of hard-coding the owner's name.
  - `styles.ts`: shared class strings (`focusRing`, `pageWidth`, `chip`).
  - `section/section.tsx`: the wrapper every homepage section uses (numbered `~/id` label, heading, sticky-nav scroll offset).
  - `nav/section-links.tsx`: the ordered list of sections (id, label, icon, tint) that drives the sticky nav and hero links. Adding a section means adding it here and rendering it in `home.tsx`.
- **Contact form**: the home route's `action` delegates to `components/contact/contact-action.ts`, which validates and has a honeypot field (`website`). It does not send mail yet; messages only go to the server log.
- **AI chat** currently answers with `components/ai/dummy-answer.ts`, a placeholder. No model is wired up.
- **Route types** come from generated `./+types/<route>` imports (e.g. `Route.LoaderArgs`, `Route.MetaFunction`). They live in `.react-router/types/` and are regenerated by `typegen`, `dev`, and `build`. Run `pnpm typecheck` after adding or renaming routes.
- **Path alias:** `~/*` maps to `app/*`.
- **Styling:** Tailwind v4 is set up through the Vite plugin, with no `tailwind.config`. Theme tokens go in the `@theme` block in `app/app.css`: fonts, the palette (`ochre`, `ochre-deep`, `ink`, `lake`, `night`) and the animations with their keyframes. The same file defines the `glass` utility (frosted panel) and the `.glass-button` class. Dark mode follows `prefers-color-scheme`. Animations are applied with `motion-safe:`, and JS-driven motion checks `prefers-reduced-motion`.
- **Static assets** are in `public/`: `portrait.jpg` (the hero) and `logos/` (company and school logos for the Experience section).

## Gotchas

- The `Dockerfile` uses `npm ci` and copies `package-lock.json`, but the repo only has `pnpm-lock.yaml`. The Docker build will fail until the two match.
- `.agents/skills/react-router/` contains a React Router skill with references for each mode. Its `framework-mode.md` covers this app's mode.
